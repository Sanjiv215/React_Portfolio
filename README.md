## 🚀 Overview

A high-performance personal developer portfolio and interactive operating system simulator designed with a **macOS Tahoe** aesthetic. Built with React 19, Vite, and Tailwind CSS v4, it highlights full-stack web applications, open-source security utilities, and agentic AI platforms.

### ✨ Highlights & Features

- **macOS Tahoe Desktop Interface**: Native menu bar, custom 'S' monogram system menu, dynamic clock, and animated dock with spring physics.
- **Interactive Developer CLI**: In-browser terminal emulator supporting custom commands (`vigilo`, `smartbuy`, `projects`, `skills`, `education`, `sudo hire-me`).
- **Live AST Security Scanner Simulator**: Interactive code editor running simulated AST-based CWE vulnerability detection (CWE-95, CWE-89, CWE-798, CWE-78).
- **Curated Projects Showcase**:
  1. **SmartBuy-AI** — Intelligent agentic browser for real-time e-commerce price comparison.
  2. **VIGILO** — Python static security scanner published on PyPI (`pip install vigilo`).
  3. **ERP Portal** — Enterprise Resource Planning system engineered during IIT Patna internship.
  4. **PySentra** — Open-source Python AST diagnostic and security monitoring utility.
  5. **My Portfolio** — Vite & React 19 portfolio web experience.
- **Freelance Client Deliverables**: Bespoke portfolio web deliverables for client engagements (Jishnu, Devendra).
- **Communication Hub**: Integrated contact card with direct email, phone/WhatsApp copy triggers, and EmailJS form dispatch.
